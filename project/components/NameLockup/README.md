# NameLockup

The two-weight name: first name in `name-light` (300) over surname in `name-bold` (800), both uppercase in `ink`.

**You provide** `first` and `last`. `size` scales both lines together (default 56px), `align` sets `start` or `center`, and `as="h1"` makes it the page title. Set it above the wordmark with `space-6` between.

Keep the order light over bold. Don't set both lines in one weight, colour them, or give them glow.
