# Highlight

An ExtraBold word in a glow tint, used inside a `Statement` or a line of display type.

**You provide** the word or phrase as children and a `tone`: `pink` (strategy and people; the default), `cyan` (technology) or `violet` (only for the word between a pink one and a cyan one). It takes its size and tracking from the text around it.

Read the highlighted words alone: they should still say the point. Don't use it in body copy, where bold `ink` is enough.
