# Eyebrow

A small uppercase marker between two neon rules, pink fading in from the left and cyan fading out to the right, like "EST. 2003" above the name.

**You provide** two or three words as children; they render in the `eyebrow` style in `ink-muted`. Each rule is `space-8` long and shrinks when space runs out.

Use it to date or place what follows ("Est. 2003", "Case study · 2026"). Don't use it as a heading or inside a panel tab.
