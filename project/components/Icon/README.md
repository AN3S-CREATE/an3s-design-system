# Icon

The eight two-tone neon line icons: primary form in `pink`, detail in `cyan`, 2px round strokes on a 48-unit grid, with a soft glow.

**You provide** `name`, one of `ai-systems`, `business-growth`, `web-app-development`, `experimental-marketing`, `brand-strategy`, `3d-virtualization`, `sales-leadership`, `innovation-mentorship` (listed in `Icon.names`). Use 48px (`icon-tile`) in tiles and 20px (`icon-inline`) with `glow={false}` beside text. Add a `title` only when no visible label says the same thing.

Do give each discipline its one icon, every time. Don't recolour, fill or swap the tones (pink is the form, cyan the detail), and don't place them on light grounds: they are drawn as light. The same drawings ship as SVG files in the Icons asset group for slides and documents.
